# 智能医院管理系统

基于 [RuoYi-vue-pro](https://github.com/YunaiV/ruoyi-vue-pro) 的医院数据管理系统，数据库原理课程设计项目。

## 技术栈

| 层级 | 技术 |
|------|------|
| 前端 | Vue 3 + Element Plus + yudao-ui-admin-vue3 |
| 后端 | Spring Boot 2.7 + MyBatis-Plus + RuoYi-vue-pro |
| 数据库 | OpenGauss（华为，兼容 PostgreSQL） |
| 缓存 | Redis |
